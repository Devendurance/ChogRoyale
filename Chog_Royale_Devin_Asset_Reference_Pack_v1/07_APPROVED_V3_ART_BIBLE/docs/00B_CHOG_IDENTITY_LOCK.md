# CHOG ROYALE — FINAL CHOG IDENTITY & COMMANDER / NFT FIDELITY LOCK (v3)

## Core rule
This overhaul is **not** a free redesign into generic polished mobile-game characters.
It is a faithful visual upgrade of **existing Chog Royale identities** into a brighter, richer, premium stylized 3D-inspired look.

If there is ever a tradeoff between:
- **looking more generically polished**, and
- **still looking recognizably like the original Chog Royale unit**,

then **recognizable Chog Royale identity wins**.

## Identity priority order
1. **Original 25-card roster references** (`BEFORE_roster_25_cards*.png`) are the canonical identity anchors.
2. Character-specific must-keep traits listed in `docs/01_ART_BIBLE.md`.
3. Approved five-character poster is a **quality / render / mood** benchmark, not permission to replace species/commander likeness.
4. New art may improve materials, depth, lighting, posing, silhouette clarity, and costume finish only while preserving identity.

## Non-negotiable preservation rules
### A. Chog species continuity
For Chog-type troops and creatures, preserve:
- big expressive Chog eye language
- compact cute-but-battle-ready creature anatomy
- recognizable head-spike/quill/crest arrangements
- familiar cheek/face proportions
- existing elemental identity and major color logic
- playful, mischievous, heroic Chog energy

Do **not** replace Chog faces with generic polished fantasy mascots.
Do **not** flatten all Chogs into one repeated face template.

### B. Commander / NFT recognizability
For Bulwark, Reaver, Deadeye, Scout, and Warden, preserve the original commander/NFT identity:
- face identity and overall silhouette
- signature helmet / hat / visor / hood / bubblegum / crest / cap / glasses
- main outfit concept and core accessory set
- main color identity
- the reason a fan would recognize the NFT/commander at first glance

These are **upgraded translations**, not loose reinterpretations.

### C. Signature props must survive
Never remove or trivialize a unit's defining prop or motif.
Examples:
- Gale Netter = visible net
- Warden = star wizard hat + bubblegum + wand/arcana
- Bulwark = red crest helmet + shield
- Chog Guardian = shield-forward blue armored defender
- Chaos Archer = clearly readable bow
- Decoy Totem = decoy/totem face identity

### D. Upgrade polish, not soul
Safe things to improve:
- better materials and shading
- more dimensional rendering
- cleaner silhouette separation
- richer lighting
- more intentional costume breakdown
- stronger pose and expression
- improved readability at battle scale

Unsafe things to change:
- species/facial structure beyond recognizability
- commander silhouette beyond recognizability
- removing iconic accessories
- turning Chogs into generic humans/creatures
- changing the underlying personality of the card

## Practical review questions for every redesign
Before approving a unit, answer YES to all:
1. If shown beside the original card art, does this still clearly read as the same Chog Royale unit?
2. Would a player who knows the commander/NFT still recognize the character immediately?
3. Are the must-keep props/accessories present and prominent?
4. Does the unit still feel Chogy, not like another game's cast?
5. Has the upgrade improved polish without erasing identity?

If any answer is NO, the redesign has drifted too far.

## How Codex should use this
- Treat identity drift as a bug, not a subjective note.
- If asset production choices conflict with this lock, stop and document the conflict.
- Do not claim a character is approved if it looks cleaner but no longer reads as the same unit.
