# A4.2 Commanders Gallery Checkpoint

Date: 2026-10-23

## Slice
A4.2 commanders gallery. Completed as one bounded slice on top of A4.1.

## What works
- `/app/commanders` renders inside the shared `/app` layout with the Privy provider and the server-built ruleset catalog.
- The five real free classes are shown from `catalog.commanders`: Bulwark, Reaver, Deadeye, Scout and Warden.
- Each card shows the free commander name, class, real deploy cost, authored role and class art label.
- The featured commander stage reuses `CommanderStage`. Selecting a card updates the stage and the class detail panel.
- The detail panel shows the authored role, active ability name, authored counters and the real class combat rows from `commanderStatRows`.
- Genesis entries come only from `GET /api/players/me/commanders`. They are shown separately from the free classes.
- Cached eligibility is labelled as a cached ownership observation, never as proof. Unproven and pending tokens stay unproven. Only `https` token art from the route is used, with shared class art as the fallback.
- Free and Genesis commanders of one class show the same class numbers.
- Browsing is read-only. The screen never reads, writes or drafts a loadout. The only deck action is a link to `/app/decks`.
- The existing Commanders tab is active and points at `/app/commanders`. Lobby, Decks, Progress, Profile and the HUD Settings link are unchanged.
