## Gotchas

- `--color-chog-ink-55` is `rgba(27,17,64,.55)`, which measures 3.98:1 on white, not the 5.6:1 that DESIGN.md states. `--color-chog-ink-70` measures 6.65:1. The public site uses ink-55 for footer links and section notes because DESIGN.md prescribes it, so any WCAG AA pass on those strings needs a token change, not a copy change.
- A CSS `mask-image` of repeating radial gradients cuts a scalloped crest into a hill layer, and the mask also clips the layer's `::before` and `::after`, so any crest highlight has to live inside the masked element to follow the scallops.
- An absolutely positioned element with a percentage `left` is shrink-to-fit, so a wide child near the right edge of its container gets squeezed. Set `width: max-content` when the child must keep its own size.
- Cache Components (next.config `cacheComponents: true`) keeps previously visited routes mounted but hidden after client navigation. CSS like `html:has(.site-root)` then leaks into `/dev/battle`. Apply html-level site rules from an effect (`SiteDocumentFlags` adds `html.site-doc`) so they follow mount lifetime.
- Public site copy source is `docs/Chog Royale messaging.md`. Owner `DESIGN.md` at repo root matches the handoff `source-docs/chog-royale-DESIGN.md` byte for byte. Both were untracked on 2026-10-21.
- Site sections compose as: a server component in `src/components/site/` gathers display data and a client component under it owns the interaction. Card and commander display data is read from `CARDS_V1`, `CLASS_ROSTER` and `COMMANDER_COMBAT_PROFILE_V1` at build time, never hardcoded, and never a token likeness.
- When a section crops art against its own edges, measure the source PNG's painted alpha bounds first (canvas `getImageData` in the browser) instead of trusting the file size, and check text and art separation with per-line `Range.getClientRects()`. Element boxes are full width for block text and give false collisions.
- A hover lift must use the independent `translate` property, not `transform`. A scroll entrance animation on `transform` overrides the hover transform, because the animation wins on the same element.
- Grid cells with a shared hairline use `gap: 1px` plus an opaque background on the grid container, so the 1px reads as one continuous divider instead of a hole. `.site-loop` (L2) and `.site-grid` (L5) both do this.
- Pointer-tracked spotlights: put the position in CSS custom properties on the cell (`--spot-x`, `--spot-y`, `--spot-a`) and set them from one `onPointerMove`. `rgb(R G B / var(--alpha))` resolves correctly in Chrome, Firefox and Safari, so a single gradient can change strength on hover without duplicating the background. Gate the tracking on `pointerType === "mouse"` so a tap cannot leave the light stuck under a finger, and put every `:hover` rule inside `@media (hover: hover)`.
- A one-column mobile grid strands a narrow art tile beside dead space. Moving the art and the title onto one row with `display: grid` on the cell cut the mobile cell from 694px to 425px and reads as a specimen list.
- A long-running Turbopack dev server on :3000 can stop answering navigations and `curl` (it held the HMR connection open). For landing-page QA, `next start` on :3100 against the production build served the marketing page in 80ms. :3100 stays blocked for Privy-gated routes because of the frame-ancestors allowlist, so keep :3000 for auth work.
- `next build` replaces the chunk manifest, so a `next start` server that is already running serves 500s on the stale build. Restart it after every rebuild before capturing screenshots.
- Editing `next.config.ts` restarts `next dev`. On 2026-10-21 the already running :3000 server exited instead of restarting, so check the port after config edits.
- `next build` can fail on a transient fonts.googleapis.com fetch error. Retry before changing font setup.
- Satoshi is self-hosted under ITF FFL 2.0: self-hosting for our own sites is allowed, but no subsetting, format conversion or redistribution. The WOFF2 lives in the private repo; making the repo public would count as redistribution.
- Don't fade hero text in from opacity 0. Chrome skipped it for LCP and picked a late below-fold element (up to 2.8s). Transform-only entrance keeps hero LCP at 0.7-1.3s locally.
- Absolute decorative glows in the last section need `overflow: clip` on the section, or they extend the document and show a white band at the page end.
- Next.js 16 no longer overrides html `scroll-behavior: smooth` on route changes unless `<html data-scroll-behavior="smooth">` is set. The site sets both together in `SiteDocumentFlags`.
- A "1 Issue" dev indicator from a body attribute mismatch (`data-gr-ext-installed`) comes from the Grammarly extension, not the app. Check the dev server's forwarded `[browser]` log before chasing it.
- A section with `overflow: clip` hard-cuts any glow that extends past its top edge. Size halos to fit inside the section or the seam shows on desktop.
- Overlapping a later section into an earlier one (negative margin) needs a transparent top in its gradient, or a white band shows over the earlier section's tint.
- Playwright programmatic scroll can make a lazy below-fold image the LCP candidate and trigger Next's dev "add loading=eager" warning. Real user scroll input ends LCP first, so check with wheel scrolling before chasing it.
- Tailwind `@theme inline` tokens emit no CSS variables. Use the utility class (e.g. `font-site`) rather than `var(--font-site)` in plain CSS.

## B3.1 battle transport (Colyseus 0.18)
- Never set `client.auth.token` in @colyseus/sdk: it appends `_authToken=<token>` to the WebSocket URL. Pass the Privy token as `new Client(url, { headers: { authorization } })`; only the matchmaking POST carries it, read by the room's static `onAuth`.
- @colyseus/ws-transport imports `express` statically despite listing it as optional; express 5.2.1 is a direct dep.
- `npm run battle:server` takes about 20s to start (Privy server-auth import graph). Killing the npm shell can leave the tsx child listening on 2567.
- npm installs need `--legacy-peer-deps` because of the pre-existing @types/node ^20 vs vitest peer conflict.
